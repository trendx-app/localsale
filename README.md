# LocalSale 공유 랜딩 — https://trendx-app.github.io/localsale/

세일 공유 링크(`?sale=<id>`)의 랜딩. 앱이 있으면 딥링크로 열고, 없으면 스토어로 보낸다.
원본은 앱 repo `LocalSale/deeplink/localsale/index.html` — **그쪽을 고치고 여기로 복사**한다.

- Android App Links 검증(`.well-known/assetlinks.json`)은 이 리포가 아니라
  **공용 루트 리포 `trendx-app/trendx-app.github.io`** 에 있다(도메인 루트에서만 서빙되므로).
